# مشروع صفحة هبوط شركة الأوائل لنقل العفش بالرياض (Native PHP & Internal SQLite / MySQL)

نسخة احترافية كاملة ومحسنة لموقع صفحة الهبوط [https://elawael.vercel.app](https://elawael.vercel.app) مبنية بلغة **PHP Native (نورمل)** نظيفة بدون أي أطر عمل ثقيلة، مع **قاعدة بيانات داخلية مدمجة داخل ملفات المشروع (`data/database.sqlite`)** تتيح لك رفع المشروع مباشرة على **GitHub** والنشر على **Vercel** بضغطة زر واحدة دون الحاجة لأي خوادم قواعد بيانات خارجية أو إعدادات معقدة!

---

## 🌟 ميزات المشروع الاستثنائية

1. **قاعدة بيانات داخلية مدمجة بالكامل (`data/database.sqlite`)**:
   - قاعدة البيانات موجودة كملف داخلي مباشر داخل مجلد `data/database.sqlite`.
   - عند رفع ملفات المشروع إلى **GitHub**، يتم رفع قاعدة البيانات بالكامل مع نصوصها وصورها وباقاتها وإعداداتها مباشرة!
   - لا حاجة لإنشاء قاعدة بيانات يدوياً أو استيراد ملفات إذا كنت تريد العمل الفوري.
   - يدعم أيضاً التحويل التلقائي إلى خادم **MySQL** عند الرغبة (الملف `database.sql` متوفر أيضاً).

2. **تصميم فاخر متطابق مع الموقع المرجعي 100%**:
   - مطابقة تامة للألوان الأصلية (خشب الجوز الملكي، البيج الرملي، التراكوتا، والذهبي).
   - خطوط عربية أنيقة من جوجل (Cairo و Tajawal).
   - أزرار اتصال عائمة (واتساب مباشر + اتصال هاتفي) وزر العودة للأعلى.
   - نافبار ذكي متجاوب مع قائمة منزلقة للهواتف (Offcanvas).
   - قسم بطل تفاعلي مع خلفية جزيئات متحركة وبطاقات عائمة وعدادات أرقام حية.
   - معرض أعمال ميداني يضم **32 صورة حية أصلية** مع لايت بوكس (Lightbox) للتكبير والتنقل بالأسهم.
   - باقات أسعار وعروض حصرية مميزة مع تمييز باقة الـ VIP الأكثر طلباً.
   - نموذج حجز تفاعلي يرسل البيانات بتقنية **AJAX** ويحفظها مباشرة في قاعدة البيانات.

3. **لوحة تحكم إدارية عصرية وشاملة (Admin Dashboard)**:
   - تصميم عربي RTL متجاوب وسريع.
   - تحكم كامل في نصوص الموقع: العناوين الرئيسية، الفقرات، نسبة الخصم، سلوجان الموقع.
   - تغيير الشعار والأيقونة ووسائل الاتصال (رقم 1، رقم 2، واتساب، البريد، العنوان، ساعات العمل).
   - إدارة الخدمات (إضافة، تعديل، حذف، تغيير الأيقونات والمميزات).
   - إدارة شاحنات الأسطول والمعدات (الأوناش وخامات التغليف).
   - إدارة معرض الأعمال (رفع صور جديدة، تغيير الأوصاف والتصنيفات، الحذف).
   - إدارة باقات الأسعار وميزات كل باقة.
   - إدارة خطوات العمل الخمس وميثاق الضمانات الأربعة.
   - إدارة آراء وتقييمات العملاء والأسئلة الشائعة ومقالات دليل السيو.
   - جدول استقبال ومتابعة طلبات الحجز مع إمكانية التواصل الفوري عبر الواتساب أو الهاتف وتحديث حالة الطلب (جديد / تم التواصل / مكتمل).
   - تغيير اسم المستخدم وكلمة المرور وحماية الصفحات بجلسات مشفرة وتأمين CSRF.

4. **أرشفة قوية وتهيئة لمحركات البحث (SEO Ready)**:
   - وسوم Meta Tags ديناميكية قابلة للتعديل لكل من `title`, `description`, `keywords`, `author`, `robots`.
   - كود بيانات منظمة **Schema.org JSON-LD** لشركات النقل والأنشطة المحلية (LocalBusiness / MovingCompany).
   - وسوم Open Graph و Twitter Cards للمشاركة الجذابة على منصات التواصل.
   - خريطة موقع ديناميكية `sitemap.php` وملف `robots.txt` لتوجيه عناكب البحث.

- **كلمة المرور:** `admin123`
*(يمكنك تغييرها بسهولة من داخل لوحة التحكم عبر صفحة "حسابي والأمان")*

## 🚀 طريقة الرفع على GitHub والنشر على VERCEL.APP

بما أن قاعدة البيانات مدمجة كملف داخلي داخل المشروع (`data/database.sqlite`)، فإن عملية النشر أصبحت في غاية السهولة:

### 1. الرفع على GitHub:
افتح مجلد المشروع في سطر الأوامر أو Git وارفع الملفات مباشرة:
```bash
git init
git add .
git commit -m "Initial commit of Elawael Landing Page & Admin"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### 2. النشر على Vercel:
1. ادخل إلى موقع [https://vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط **Add New Project** واختر المستودع الذي رفعته للتو.
3. اضغط زر **Deploy** مباشرة (بدون الحاجة لإدخال أي بيانات قاعدة بيانات خارجية).
4. سيتولى ملف `vercel.json` المرفق مع المشروع تشغيل بيئة الـ PHP وقاعدة البيانات الداخلية فوراً!

## 💻 طريقة التشغيل محلياً على جهازك

المشروع لا يحتاج لتثبيت سيرفر MySQL للعمل، فقط شغل أمر PHP المدمج:
```bash
php -S localhost:8000
```
ثم افتح الرابط: `http://localhost:8000/`

*(وإذا كنت تستخدم XAMPP أو Laragon وترغب باستخدام MySQL، يمكنك استيراد ملف `database.sql` وتغيير `DB_TYPE` في ملف `config.php` إلى `mysql`).*
